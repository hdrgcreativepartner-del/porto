# Logo klien

Drop logo di folder ini, lalu **Commit changes** ke branch `main`. Logo akan muncul otomatis setelah GitHub Pages selesai menerbitkan website.

Lebih mudah: buka **[Panel admin](https://hdrgcreativepartner-del.github.io/porto/admin/) → Logo klien** untuk mengunggah, mengganti nama, memilih latar, atau menghapus logo.

- Rekomendasi kanvas: **800 × 400 px** (2:1).
- PNG transparan / WebP transparan atau SVG. JPG dan AVIF juga bisa.
- Sisakan ruang aman 10–15% di sekeliling logo; jangan diregangkan.
- Target ukuran file: **di bawah 200 KB**.
- Satu logo per file. Contoh: `idnog.png`, `universitas-jember.svg`.
- Logo putih: beri akhiran **`--dark`**, contoh `nama-klien--dark.png`. Website akan memakai latar gelap.
- Logo lain ditampilkan pada latar putih, dengan warna aslinya.
- Urutan mengikuti nama file. Awali `01-`, `02-` bila ingin mengatur urutan melalui folder.
- Jangan membuat subfolder. File dengan awalan `_` atau `.` diabaikan.

Folder belum berisi logo klien karena menunggu aset resmi dari pemilik. Nama pengalaman yang sudah ada tetap tampil sampai logo pertama diunggah.
