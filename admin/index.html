ADMIN ACCESS

Masuk ke studio.

Hubungkan akun GitHub yang memiliki akses tulis ke hdrgcreativepartner-del/porto.

Token digunakan langsung ke GitHub dan hanya berada di memori tab ini. Muat ulang halaman atau keluar untuk mengakhiri sesi.

Belum punya token? Ikuti 4 langkah ini.
  1. Buka pembuatan fine-grained token di GitHub ↗.
  2. Pilih resource owner hdrgcreativepartner-del. Pada repository access, pilih Only select repositories → porto.
  3. Beri izin repository Contents: Read and write. Atur tanggal kedaluwarsa, lalu klik Generate token.
  4. Salin token ke kolom di atas. Simpan salinannya di pengelola sandi Anda agar bisa masuk lagi nanti.

Ini akses dengan token GitHub, bukan login memakai password GitHub. Jangan membagikan token melalui chat atau memasukkannya ke file repo.
